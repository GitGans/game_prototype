# Visual Style: Pixel Art Units

_Date: 2026-04-02_

---

## Общий подход

Юниты отрисованы как pixel art — двумерные матрицы палетных индексов, рендерящиеся в Phaser-текстуры через Canvas API. Никаких внешних файлов — всё генерируется кодом при старте сцены.

---

## Палитра

Единая палитра для всей игры (`GAME_PALETTE`). Ключевые группы:

- **Тёмный контур** — почти чёрный `#1a1a2e`, единый для всех спрайтов. Обеспечивает читаемость на тёмном фоне.
- **Игрок (синяя сторона)** — три оттенка синего: светло-синий для бликов/деталей, средний для основного тела, тёмный для теней и контрастных зон.
- **Враги (красная сторона)** — два оттенка красного: основной и тёмный. Красный намеренно "горячий" и агрессивный в отличие от холодного синего игрока.
- **Нейтральные** — золото (акценты, обводки шлема), скин (лица), белый (глаза, зубы), зелёный (гоблин), пурпурный (магия).

Цвет стороны (синий / красный) — первый визуальный сигнал. Игрок видит фракцию раньше, чем читает имя.

---

## Стиль спрайтов

**Силуэт первичен.** Каждый юнит узнаётся по форме контура без цвета:

| Юнит | Ключевая форма силуэта |
|------|------------------------|
| Knight | Широкие наплечники, щелевой визор, зазор между ногами |
| Archer | Лук, выступающий влево, узкое тело, капюшон |
| Mage | Заострённая шляпа, расширяющийся к низу балахон |
| Goblin | Большие уши по бокам головы, сгорбленная фигура |
| Orc | Очень широкое тело (занимает 2 клетки), почти нет шеи, клыки |
| Shaman | Два рога сверху, балахон, магический орб на посохе |

**Минимум деталей** — читаемость при малом размере важнее реализма. Глаза — 1–2 пикселя высококонтрастного цвета. Блики — один-два светлых пикселя. Анимации не используются на этом этапе.

---

## Интеграция в UnitView

Спрайт заменяет прямоугольный фон (`bg`) внутри контейнера `UnitView`. Поверх спрайта остаются:
- Имя юнита (с тёмной обводкой для читаемости на любом фоне)
- HP-текст и HP-бар у нижнего края

Мёртвый юнит: спрайт тонируется серым, прозрачность снижается.

---

## Что намеренно оставлено простым

- **Клетки** — остаются геометрическими прямоугольниками. Визуальная сложность нужна на юнитах, а не на сетке.
- **Инициативная шкала** — простые цветные карточки. Не трогалась.
- **Анимации** — не реализованы. При необходимости: `renderSpriteSheet()` уже есть в `PixelRenderer.ts`, достаточно добавить кадры в матрицу.

---

## Технический стек визуала

- `src/core/PixelRenderer.ts` — `renderPixelArt(scene, pixels, palette, key, scale)` и `renderSpriteSheet()` (для будущих анимаций)
- `src/sprites/palette.ts` — единая палитра
- `src/sprites/units.ts` — матрицы спрайтов + маппинг `unitId → textureKey`
- `pixelArt: true` в Phaser-конфиге — nearest-neighbor фильтрация (без размытия при масштабировании)
