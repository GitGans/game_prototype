# Project Status: Battle System Prototype

_Date: 2026-04-02_

---

## Immutable Architectural Rules (from original spec)

### Core Rule

> **Logic computes → Phaser renders**
>
> - `battle/` never imports Phaser
> - Phaser scenes contain no game rules

### Integration Pattern (required for all new features)

```
Input (player click / enemy action)
  → pass to battle function
  → receive new BattleState
  → emit STATE_CHANGED
  → Phaser updates visuals based on new state
```

### Cell-based System (fundamental field rule)

- **Cell is the base unit** of the system, not the unit/character
- An attack selects a cell or set of cells
- An effect is applied to a unit if it **occupies** that cell
- Front row is checked through cells: if at least one front-row cell is occupied by a living unit → row is alive

### Attack — always a sequence of steps (mandatory order)

1. Determine target cells
2. Validate them against attack rules
3. Find units in those cells
4. Deduplicate (one unit = one effect)
5. Apply effect

### Allowed Unit Shapes

`1x1`, `1x2` (1 row 2 cols), `2x1` (2 rows 1 col), `2x2` — defined in `shapes.ts` as `SHAPES`

## Key Data Structures

### BattleState (types.ts)

```ts
interface BattleState {
  units: Map<string, Unit>; // all units
  occupancy: OccupancyMap; // cell↔unit bidirectional map
  roundQueue: string[]; // turn queue; [0] = currently acting unit
  phase: "select_target" | "end";
  validTargets: CellCoord[];
}
```

### Unit (types.ts)

```ts
interface Unit {
  id: string;
  name: string;
  hp: number;
  maxHp: number;
  initiative: number;
  shape: UnitShape; // offsets: [{dr, dc}]
  anchor: CellCoord; // { side, row, col }
}
```

### CellCoord

```ts
type Side = "player" | "enemy";
type Row = 0 | 1; // 0 = front (closest to enemy), 1 = back
type Col = 0 | 1 | 2;
```

## Grid Orientation (IMPORTANT)

```
[Player Back (row=1)] [Player Front (row=0)] | [Enemy Front (row=0)] [Enemy Back (row=1)]
         col 0=bottom, col 1=mid, col 2=top
```

- **row** → horizontal strip: for player, front (row=0) is RIGHTMOST; for enemy, LEFTMOST
- **col** → vertical position within strip: 0=bottom, 2=top
- Pixel position formula: `cellPixelPos(side, row, col)` in `Game.ts`
- Canvas 900×500, grid shifted down +40px (room for initiative bar)

## Turn Flow (Game.ts)

```
create()
  → seedUnits()
  → buildRoundQueue()            ← initiative.ts
  → startActiveUnitTurn(state)

startActiveUnitTurn(state):
  activeUnit = units.get(roundQueue[0])
  if player:  phase='select_target', emit STATE_CHANGED, wait for click
  if enemy:   700ms delay → enemyTurn()

onCellClick(coord):
  → handleTargetSelect(coord, state)
      → resolveAttack([coord], DAMAGE, state)   ← combat.ts
      → checkGameOver(next)
      → advanceQueue(next)                      ← pruneQueue + buildRoundQueue
      → startActiveUnitTurn(next)

advanceQueue(state):
  remaining = roundQueue.slice(1)
  remaining = pruneQueue(remaining, units)      // remove dead units
  queue = remaining.length > 0 ? remaining : buildRoundQueue(units)  // new round
```

---

## Combat Rules

1. **Melee targets**: if enemy front row is alive → front row only; else → back row
2. **Deduplication**: if a unit occupies multiple target cells — effect applied once
3. **Initiative**: sorted descending; ties → interleave player first, then enemy
4. **Round**: each unit acts once; after the last one — queue rebuilds
5. **Dead units**: removed from queue via pruneQueue() after each attack
